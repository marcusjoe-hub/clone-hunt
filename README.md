# 🕵️ Clone Hunt: Hide & Seek
Official showcase website for the Roblox game Clone Hunt.

## 🎮 Play Now
[Play on Roblox](https://www.roblox.com/games/131083771121188/Key-Hunt)

## ⚡ Features
- 90-second rounds
- Identical player clones
- Seeker clone decoys
- Pure paranoia

## 🛠️ Tech Stack
- HTML5 + CSS3 + Vanilla JS (ES Modules)
- Canvas API particles
- Web Audio API music player
- Deployed on Render via GitHub auto-deploy

## 📁 Adding Updates
Edit `js/updates-data.js` and push. The site auto-updates.
